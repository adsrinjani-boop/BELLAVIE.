BELLAVIE - Toko Online (HTML + CSS + Vanilla JavaScript murni)

Isi:
- index.html  : struktur halaman
- style.css   : desain (tema oranye/putih)
- script.js   : logika (produk, filter, pencarian, keranjang, wishlist, newsletter)

Cara pakai:
1. Ekstrak folder ini.
2. Buka index.html dengan browser (double klik). Selesai — tanpa install apa pun.

Catatan:
- Gambar diambil dari Unsplash (gratis) lewat URL. Ganti URL-nya di script.js
  (array `products` dan `categories`) dengan foto produk kamu sendiri.
- Keranjang & wishlist tersimpan di localStorage browser.
